💬 الرسائل العائلية
التعديلات تظهر في الشريط المتحرك فوراً عند الإضافة/التعديل/الحذف، وتُنشر على ملف content.json في GitHub (مستودع prayer-times) عند الضغط على ☁️. كل رسالة تحفظ تاريخ ووقت إضافتها أو تعديلها 🕐.
🔑 رمز GitHub غير محفوظ
للحفظ على GitHub يلزم رمز وصول شخصي (Token):
1️⃣ github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
2️⃣ Generate new token (classic) مع تفعيل صلاحية repo
3️⃣ الصق الرمز هنا واضغط حفظ — يُخزَّن في جهازك فقط.
🗄️ النسخ الاحتياطي الكامل إلى GitHub
يرفع كل ملفات البرنامج إلى المستودع بضغطة واحدة لسهولة الإصلاح والتعديل مستقبلاً: التطبيق prayer-times.html + الصوتيات العشرة في public/ + تطبيق APK (إن وُجد بجانب الصفحة).
⚠️ لا يُمسّ ملف الرسائل content.json — يُحفظ تلقائياً من المحرر أعلاه.
