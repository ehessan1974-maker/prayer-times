## 📲 التحميل

الطريقة الرسمية الوحيدة للحصول على التطبيق:

**https://ehessan1974-maker.github.io/prayer-times/**

من صفحة التحميل يمكنك:
- تحميل تطبيق أندرويد (APK) مباشرة عبر ثلاثة روابط بديلة
- مسح رمز QR لتحميل أسرع من الجوال

## ✨ الميزات

- 🕌 **مواقيت صلاة دقيقة**: حساب فلكي يعتمد GPS أو الإحداثيات اليدوية أو اختيار المدينة
- 📢 **أذان وإقامة وتنبيهات**: أصوات أذان وإقامة ودعاء وعدّ تنازلي صوتي
- 🧭 **بوصلة القبلة**: تفاعلية بحساس الاتجاه مع دعم إذن iOS
- 🌙 **الوضع الليلي/النهاري**: محفوظ محلياً تلقائياً
- 📺 **وضع الشاشة الذكية**: عرض 1600×900 بلا تمرير مناسب للشاشات الذكية وشاشات المساجد
- 📜 **شريط رسائل متحرك**: يُدار من داخل التطبيق
- 📻 **إذاعة واختيار المدن** + إعادة معايرة
- 🔌 **يعمل بلا إنترنت** بالكامل بعد التثبيت
