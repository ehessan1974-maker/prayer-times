> تطبيق مواقيت صلاة شامل: حساب فلكي دقيق، أذان وتنبيهات صوتية، بوصلة قبلة، ووضع للشاشات الذكية — يعمل بلا إنترنت.

## 📲 التحميل

صفحة التحميل الرسمية:

**https://ehessan1974-maker.github.io/prayer-times/**

من صفحة التحميل يمكنك:
- **فتح النسخة الإلكترونية (HTML) مباشرة في المتصفح بلا أي تحميل** — [ehessan1974-maker.github.io/prayer-times/prayer-times.html](https://ehessan1974-maker.github.io/prayer-times/prayer-times.html)
- تحميل تطبيق أندرويد (APK) مباشرة عبر ثلاثة روابط بديلة
- تحميل ملف HTML للاستخدام دون اتصال (يُحدَّث تلقائياً عند فتحه مع وجود إنترنت)
- مسح رمز QR من الجوال: لتحميل الـAPK أو لفتح النسخة الإلكترونية فوراً
- الاطلاع على «ما الجديد» في أحدث إصدار مباشرة من الصفحة

## ✨ الميزات

- 🕌 **مواقيت صلاة دقيقة**: حساب فلكي يعتمد GPS أو الإحداثيات اليدوية أو اختيار المدينة
- 📢 **أذان وإقامة وتنبيهات**: أصوات أذان وإقامة ودعاء وعدّ تنازلي صوتي
- 🧭 **بوصلة القبلة**: تفاعلية بحساس الاتجاه مع دعم إذن iOS
- 🌙 **الوضع الليلي/النهاري**: محفوظ محلياً تلقائياً
- 📺 **وضع الشاشة الذكية**: عرض 1600×900 بلا تمرير مناسب للشاشات الذكية وشاشات المساجد
- 📜 **شريط رسائل متحرك**: يُدار من داخل التطبيق
- 📻 **إذاعة واختيار المدن** + إعادة معايرة
- 📚 **مكتبة الأحاديث الكاملة**: 12 كتاباً (صحيح البخاري، مسلم، الكتب الستة، موطأ مالك، رياض الصالحين وغيرها) بقارئ بملء الشاشة، بحث شامل في كل الكتب يتجاهل التشكيل، وحفظ موضع القراءة
- 🔀 **ترتيب حر للبيانات المتحركة**: رتّب الأقسام والعناصر كما تحب — يُحفظ تلقائياً على جهازك
- 🔌 **يعمل بلا إنترنت** بالكامل بعد التثبيت

## 🖥️ المنصات

| المنصة | الوصف |
|---|---|
| أندرويد (APK) | التطبيق الكامل مع الأصوات والتنبيهات |
| الويب / HTML | النسخة الإلكترونية تعمل في المتصفح مباشرة — من صفحة التحميل أو بتنزيل الملف |
| الشاشة الذكية | وضع عرض خاص للشاشات الكبيرة 1600×900 |
| تشغيل تلقائي | سكربتات إقلاع لويندوز ولينكس للأجهزة المخصصة |
